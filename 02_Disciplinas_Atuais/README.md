# Disciplinas atuais

Esta área reúne os conteúdos do semestre atual. Cada disciplina possui uma pasta própria para evitar arquivos soltos e facilitar a localização de resumos, exercícios, laboratórios, projetos e entregas.

## Padrão sugerido para arquivos

- Usar nomes claros e descritivos.
- Incluir tema e data quando isso facilitar a busca.
- Separar versões de rascunho e entrega final.
- Nunca publicar senhas, tokens, dados pessoais sensíveis ou arquivos com acesso restrito.
