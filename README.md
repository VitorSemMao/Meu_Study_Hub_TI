# Meu Study Hub TI

Repositório acadêmico e profissional de **Vitor Pereira da Costa**, estudante do 8º semestre de Ciência da Computação no UniCEUB.

## Objetivo

Centralizar anotações, atividades, projetos, certificados e evidências práticas produzidas durante a graduação. A organização facilita revisões, acompanha a evolução acadêmica e ajuda a selecionar materiais relevantes para o portfólio profissional.

## Áreas de interesse

- Desenvolvimento de software
- Segurança da informação
- Redes e infraestrutura
- Automação e OSINT defensivo
